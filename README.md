# 魚心 お持ち帰りメニュー

寿司店「魚心（uoshin024）」のお持ち帰り基本メニューから、商品と個数を選んで
注文内容をテキストで出力できる単一 HTML のアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド・サーバー不要）。

1. 価格帯タブ（220円 / 350円 / 400円 / 590円 / お持ち帰り桶）で移動
2. 各商品の `＋` `−` で個数を選択
3. フッターに合計点数・合計金額（税込）を表示
4. **「テキスト出力」** で注文内容を整形テキストとして表示
5. **「コピー」** でクリップボードにコピー

### 出力例

```
【魚心 お持ち帰りご注文】

■ 220円
  ・サーモン × 2　¥440
  ・たまご × 1　¥220

■ 400円
  ・うに × 1　¥400

―――――――――――
合計 4点　¥1,060（税込）
```

## メニュー内容

Instagram 投稿（uoshin024・お持ち帰り基本メニュー）の内容をもとにしています。
価格・商品はすべて税込。その日のオススメやご予約は店舗へお電話でお問い合わせください。

メニュー項目は `index.html` 内の `MENU` 定数にまとまっているので、変更はそこを編集してください。

## とけいのべんきょう フラッシュカード（clock.html）

5歳児向けの「とけいのよみかた」フラッシュカード学習アプリです。単一 HTML で、`clock.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。

1. アナログ時計が表示され、ランダムな時刻が出題されます
2. 4択の答えからタップして回答すると、正解／不正解がその場でわかります
3. 正解するとすぐに（不正解でも少し待ってから）自動的に次の問題が出るので、テンポよく連続で出題できます
4. レベルを切り替え可能
   - ①ちょうど：〇時のみ
   - ②はん：〇時 / 〇時半
   - ③5ふんきざみ：5分刻みのすべての時刻
5. 正解数・出題数・連続正解数を画面上部に表示
